# API 测试说明

## 📋 测试覆盖范围

本测试套件涵盖 Facebook Clone API 的所有接口和功能模块：

### ✅ 测试模块清单

1. **系统健康检查** - 服务可用性验证
2. **认证模块** - 注册、登录、资料管理
3. **帖子模块** - 创建、查询、更新、删除
4. **互动模块** - 点赞、评论、回复
5. **好友模块** - 好友请求、接受/拒绝、状态检查
6. **聊天模块** - 会话列表、在线状态、未读消息
7. **通知模块** - 通知列表、标记已读、设置管理
8. **搜索模块** - 用户搜索、帖子搜索、全局搜索、标签搜索
9. **话题模块** - 话题创建、关注、热门话题
10. **上传模块** - 文件上传接口验证
11. **推荐模块** - 个性化推荐、热门帖子、智能好友推荐

## 🚀 快速开始

### 方法一：使用批处理文件（Windows）

```bash
run_api_tests.bat
```

### 方法二：使用 PowerShell（Windows）

```powershell
.\run_api_tests.ps1
```

### 方法三：直接运行 Python 脚本

```bash
python tests/test_complete_api.py
```

## 🐛 常见问题

### 1. 连接失败
**问题**: `无法连接到服务器`
**解决**: 确保服务器正在运行 `python app.py`

### 2. 认证失败
**问题**: 注册或登录失败
**解决**: 
- 检查数据库连接
- 确认邮箱格式正确
- 密码强度符合要求

### 3. 依赖缺失
**问题**: `ModuleNotFoundError: No module named 'requests'`
**解决**: `pip install requests colorama`

### 4. 测试数据冲突
**问题**: 用户已存在错误
**解决**: 测试脚本会自动使用时间戳避免冲突，如需清理可手动删除测试用户

## 📖 扩展测试

如需添加新的测试用例，在 `test_complete_api.py` 中添加测试函数：

```python
def test_new_feature():
    """测试新功能"""
    print_header("新功能测试")
    
    print_test("测试用例名称")
    response = make_request("GET", "/new-endpoint")
    if response and response.status_code == 200:
        print_success("测试通过")
    else:
        print_error("测试失败", response)
```

然后在 `run_all_tests()` 中调用即可。
