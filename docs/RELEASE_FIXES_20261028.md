- 主页资料、用户动态、用户赞过的动态统一执行主页范围；仅好友要求已接受的好友关系。未知范围从严处理。列表身份卡不包含受限主页的简介与封面，公开动态自身的可见范围保持独立。

- `@提及` 使用 SQLAlchemy Session，在内容提交后使用独立事务投递。正文、话题关联和成功响应快照在同一事务内生成，附加通知失败不再把已提交的正文变成失败响应。评论提及关联到评论编号，接收者须仍可查看原动态。

- 所有治理通知复用 WebSocket、Aliyun、APNs 的统一投递入口，继续遵守各推送偏好。
- “与你相关”在数据库分页前过滤可见范围，并以发布时间、ID 稳定排序。
