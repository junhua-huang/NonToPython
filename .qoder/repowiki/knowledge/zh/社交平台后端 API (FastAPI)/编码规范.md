- 服务层方法统一接收 `db: Session` 作为第一个参数，而非在内部创建会话，以支持事务控制和测试隔离。
- 路由函数普遍使用 `Depends(get_current_user)` 或 `Depends(get_optional_user)` 进行身份校验，并通过 Pydantic Schema 定义请求体与响应结构。
- 批量查询优化：在列表接口中（如推荐、搜索），使用 `_batch_load_post_data` 一次性加载点赞、评论、话题等关联数据，避免 N+1 查询问题。
- 敏感内容与垃圾信息检测通过 `ContentModeration` 和 `ContentFilter` 服务在发帖/评论前同步执行，拦截不合规内容并记录日志。
