- **启动命令**: `uvicorn app.main:app --host 0.0.0.0 --port 5000 --reload`
- **环境配置**: 需设置 `.env` 文件，包含 `SECRET_KEY`, `JWT_SECRET_KEY`, `DB_USER/PASS/HOST/NAME` 以及腾讯云 `COS_ID/KEY/BUCKET` 等变量。
- **数据库初始化**: 首次运行会自动执行 `Base.metadata.create_all()` 建表，也可通过 `comic_tables.sql` 和 `migrations/` 下的 SQL 脚本手动迁移特定业务表。
