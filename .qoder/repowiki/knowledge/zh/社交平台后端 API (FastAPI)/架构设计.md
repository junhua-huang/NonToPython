- **入口与路由**: `app/main.py` 作为应用入口，通过 `lifespan` 钩子初始化数据库，并集中注册了 Auth, Posts, Chat, WS 等 16+ 个业务路由模块。
- **分层架构**: 采用经典的 Controller-Service-Model 结构。`routers/` 处理 HTTP/WebSocket 请求；`services/` 封装核心业务逻辑（如推荐算法、内容审核、搜索）；`models/` 定义 SQLAlchemy 2.0 ORM 模型。
- **数据持久化**: `database.py` 配置同步 SQLAlchemy 引擎与 Session 工厂，通过 `dependencies.py` 中的 `get_db` 实现依赖注入。
- **实时通讯**: `ws_manager.py` 维护 WebSocket 连接池与消息序号机制，支持断线补发与 ACK 去重，由 `routers/ws.py` 暴露 `/ws` 端点。
- **配置管理**: `core/config.py` 基于环境变量管理数据库、JWT 密钥及腾讯云 COS 存储配置，并提供生产环境专用配置类。
